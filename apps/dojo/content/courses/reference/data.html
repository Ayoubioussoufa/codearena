Indexes

  • The unit of cost is the 8 kB page. EXPLAIN (ANALYZE, BUFFERS) counts them. A Seq Scan reads every page of the heap.
  • A B-tree is a sorted copy of some columns plus a few levels of branch pages: millions of entries in four or five levels.
  • Leftmost prefix: (a, b) serves a, or a and b; never b alone (I-16).
  • Equality columns first, then the sort or range column. Then ORDER BY … LIMIT reads only what it returns. Backwards is free.
  • Partial index: … WHERE status = 'ACCEPTED' indexes only the rows a query ever asks for: smaller and cheaper to write.
  • Every index costs every insert. Name the query each one serves; delete the ones nobody can name.

Reading a plan

  • Read from the innermost line outward. cost is an estimate; actual time is measured, in ms.
  • rows and time are per loop: multiply by loops.
  • Find the node that holds the buffers. That's where the work is.

  • Prisma 7.8: $transaction(fn, { isolationLevel: Prisma.TransactionIsolationLevel.Serializable }); 40001 and deadlocks arrive as P2034. Retry the whole transaction, a bounded number of times.
  • Test races concurrently (Promise.all), never sequentially.
