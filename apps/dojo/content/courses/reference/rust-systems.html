Processes (lesson 36)

use std::os::unix::process::{CommandExt, ExitStatusExt};
let mut child = Command::new(prog).args(rest)
    .process_group(0)                  // setpgid(0, 0)
    .spawn()?;                         // Err if it can't start (report exit 127)
match child.try_wait()? {              // waitpid(…, WNOHANG)
    Some(status) => …,                 // status.code() / status.signal()
    None => …,                         // still running
}

What unsafe allows

  • Dereferencing a raw pointer (creating one is safe) · calling an unsafe or foreign function · using a static mut · implementing an unsafe trait · reading a union field.
  • It switches nothing off: borrow and type checks still run. Write a // SAFETY: comment saying why the block is sound.

Data races don’t compile (E0499, E0277, E0373). Deadlocks do: lock in one global order.

Async with tokio (lesson 39)

  • Futures are lazy: nothing runs until .await, join!, select! or tokio::spawn.
  • Sequential awaits add up; join! takes the max; select! and timeout take the min and drop (cancel) the loser.
  • Limit concurrency with Arc<Semaphore> and acquire_owned().await inside each task; the permit frees when dropped.
  • Never block a runtime thread: CPU work or blocking calls go to spawn_blocking (or rayon).
  • Tests: #[tokio::test(start_paused = true)] with the test-util feature, for instant, exact time.
