Byte-level BPE (lesson 40)

  1. Base vocabulary: the 256 byte values. Any text encodes; nothing is unknown.
  2. Train: count adjacent pairs (overlapping); merge the most frequent into token 256, 257, … (ties: smallest pair); replace occurrences left to right, without overlap; stop at the vocabulary size, or when no pair repeats.
  3. Encode: start from the bytes; while a learned pair is present, merge the one learned earliest.
  4. Decode: expand each token to its bytes; merged tokens are their two halves.
"aaabdaaabac" → (a,a)=256 → (a,b)=257 → (256,257)=258 → [258, d, 258, a, c]

Sources: Sennrich, Haddow and Birch, ACL 2016 (arXiv:1508.07909); GPT-2’s byte-level variant (Radford et al., 2019); minbpe.

Parallel, and shipped (lesson 42)

  • use rayon::prelude::*; then items.par_iter().map(f).collect(): a pool sized to the logical CPUs (RAYON_NUM_THREADS overrides), order kept.
  • Helps for independent, big-enough pieces; not for chains (BPE training), tiny work, or one ordered output. Measured: 5.5× on 12 cores.
  • CI trio: cargo fmt --check · cargo clippy -- -D warnings · cargo test; plus cargo audit for advisories.
